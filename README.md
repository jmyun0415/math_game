# 미니게임 배틀 2.0 (Math & Mini-Game Battle with Numbers API)

2명의 플레이어가 하나의 키보드에서 대결하는 Python Tkinter 기반 수학 미니게임 프로그램입니다.  
3판 2선승제 배틀 종료 후, 게임에서 활용된 숫자를 추출하여 **외부 REST API(Numbers API)**로부터 흥미로운 수학적 사실과 상식을 실시간으로 불러와 제공하는 **'오늘의 숫자 상식(Today's Number Fact)'** 기능이 탑재되어 있습니다.

---

## 1. 실행 환경 및 방법 (UV 환경 재현)

본 프로젝트의 모든 의존성과 런타임 환경은 최신 Python 패키지 관리자인 **UV**를 통해 100% 동일하게 재현 가능합니다.

### 요구 사양
- Python 3.12 이상
- UV (Astral UV 패키지 관리자)
- Tkinter (Python 표준 라이브러리 내장)

### 빠른 실행 (Quick Start with UV)
```bash
# 1. 저장소 클론 및 디렉토리 이동
git clone https://github.com/jmyun0415/math_game.git
cd math_game

# 2. UV 의존성 동기화 (가상환경 자동 구성)
uv sync

# 3. 게임 실행
uv run python main.py
```

### 단위 테스트 실행 (Test Suite)
수론 분석 엔진, 로컬 폴백 아카이브, REST API 응답 검증 테스트를 실행합니다.
```bash
uv run python test_number_fact.py
```

## 2. API 설정 및 환경 변수 (.env) 안내

- **기본 연동 API**: Numbers API (`http://numbersapi.com`)
- **API Key 필요 여부**: Numbers API는 **별도의 인증 키 없이 무료로 호출 가능한 공개 REST API**입니다. 따라서 키를 입력하지 않아도 모든 기능이 즉시 정상 작동합니다.
- **`.env` 파일 형식 및 설정**:
  커스텀 프록시 서버나 인증 키가 필요한 외부 API 엔드포인트를 사용할 경우, 프로젝트 루트의 `.env` 파일에 아래와 같은 형식으로 설정할 수 있습니다.
  ```env
  # .env 설정 예시
  NUMBERS_API_BASE_URL=http://numbersapi.com
  NUMBERS_API_KEY=your_optional_api_key_here
  API_TIMEOUT_SECONDS=3.0
  ```
  *(저장소에는 템플릿인 `.env.example`이 제공되며, 실제 비밀 키가 담긴 `.env` 파일은 `.gitignore`에 등록되어 안전하게 제외됩니다. icampus 과제 제출 시에는 필요 시 API Key를 별도 텍스트로 제출하시면 됩니다.)*

## 3. 신규 기능: 오늘의 숫자 상식 (Numbers API 연동)

1. **게임 연동 숫자 자동 추출**:
   - 1라운드 곱셈 암산 결과, 2라운드 암기 숫자, 3라운드 소수/합성수 등 게임 진행 중 실제 문제 및 정답으로 출제된 숫자들을 히스토리로 기록하고 게임 종료 시 대표 숫자를 선정합니다.
2. **비동기 REST 통신 (`threading`)**:
   - Tkinter GUI 이벤트 루프와 분리된 백그라운드 스레드에서 `http://numbersapi.com/{number}/math?json`을 비동기 호출하여, 네트워크 통신 중에도 폭죽 애니메이션과 UI가 부드럽게 유지됩니다.
3. **무중단 다단계 로컬 폴백 (Local Fallback DB & 수론 엔진)**:
   - 네트워크 단절, Numbers API 서버 장애(404/500), 타임아웃 발생 시 자체 내장된 '수학 상식 아카이브'와 '동적 수론 분석 엔진'(소수, 완전제곱수, 2의 거듭제곱, 약수 등 분석)으로 자동 전환되어 100% 무중단으로 교육적 정보를 제공합니다.
4. **인터랙티브 보너스 퀴즈 및 상식 새로고침**:
   - 소개된 숫자와 관련된 3지선다형 보너스 퀴즈를 풀고 즉시 정답 및 해설을 확인할 수 있습니다.
   - `[🔄 다른 숫자 상식 보기]` 버튼을 눌러 추가적인 수학적 지식을 실시간으로 탐색할 수 있습니다.

## 4. 게임 규칙 및 조작법 (3판 2선승제)

1. **참가자 등록**: 시작 화면에서 플레이어 1(P1)과 플레이어 2(P2)의 닉네임을 입력합니다 (동일 닉네임 입력 불가).
2. **조작 방식**:
   - **P1**: 키보드 상단 **숫자열 키(0~9)**, 수정(**BackSpace**), 제출(**Enter**)
   - **P2**: 키보드 우측 **숫자패드(Keypad 0~9)**, 수정(**KP_Delete/BackSpace**), 제출(**Keypad Enter**)
3. **라운드 구성**:
   - **1R 암산 게임**: 3자리 × 3자리 곱셈 문제 (2문제 선취 시 승리)
   - **2R 암기 게임**: 10개의 숫자를 30초간 암기 후 지정 위치 숫자 맞히기 (2문제 선취 시 승리)
   - **3R 소수 찾기 게임**: 3자리 숫자가 소수인지 합성수인지 판별 (1: 소수, 2: 합성수, 2문제 선취 시 승리)
4. **선입력 권한 & 페널티**:
   - 먼저 숫자를 입력한 플레이어에게 10초간 입력 독점 권한이 주어집니다.
   - 오답 제출 또는 10초 시간 초과 시 **10초간 입력 불가 페널티**가 부과됩니다.
5. **최종 승리**: 먼저 2개 라운드를 승리한 플레이어가 최종 챔피언이 되며, 폭죽 축하 애니메이션과 함께 '오늘의 숫자 상식' 카드가 열립니다.
