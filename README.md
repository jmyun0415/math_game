# 미니게임 배틀 (Math & Mini-Game Battle)

2인 플레이어가 한 키보드에서 대결하는 Python Tkinter 기반 미니게임 프로그램입니다.

## 1. 실행 환경 및 방법

### 요구 사양
- Python 3.12 이상
- Tkinter (Python 표준 라이브러리 내장)
- 별도의 외부 패키지 설치 없이 표준 라이브러리만으로 실행 가능합니다.

### 실행 방법
```bash
# 1. 저장소 클론
git clone https://github.com/jmyun0415/math_game.git
cd math_game

# 2. 실행
python main.py
```

또는 `uv`를 사용하는 경우:
```bash
uv run python main.py
```

## 2. 게임 규칙 및 진행

1. **시작 화면**: 두 플레이어(P1, P2)의 닉네임을 입력하고 게임을 시작합니다 (동일 닉네임 입력 불가).
2. **조작 방식**:
   - **플레이어 1**: 키보드 상단 **숫자열 키(0~9)** 및 **Enter**
   - **플레이어 2**: 키보드 우측 **숫자패드(Keypad 0~9)** 및 **Keypad Enter**
3. **게임 구성 (3판 2선승제)**:
   - **1라운드 - 암산 게임**: 3자리 × 3자리 곱셈 문제 (2문제 선취 시 승리)
   - **2라운드 - 암기 게임**: 10개의 한 자리 숫자를 30초 동안 암기 후 특정 위치 숫자 맞히기 (2문제 선취 시 승리)
   - **3라운드 - 소수 찾기 게임**: 3자리 숫자가 소수인지 합성수인지 판별하기 (2문제 선취 시 승리)
4. **페널티 규칙**:
   - 한 플레이어가 먼저 숫자를 입력하면 10초간 입력 권한을 획득합니다.
   - 오답을 제출하거나 10초 제한 시간을 초과하면 해당 플레이어는 **10초간 입력 불가 페널티**를 받습니다.
5. **승리 조건**:
   - 3개 게임 중 먼저 2승을 거둔 플레이어가 최종 승리하며, 폭죽 애니메이션과 함께 최종 승리자가 표시됩니다.

## 3. 프로젝트 파일 구조
- `main.py`: Tkinter GUI 화면 구성 및 이벤트/타이머 처리 메인 파일
- `game_logic.py`: 게임 규칙, 문제 생성, 정답 검증 및 스코어/페널티 관리 로직
- `fireworks.py`: 최종 승리 화면 및 폭죽 캔버스 애니메이션
- `plan-1.md`: 초기 프로젝트 기획서 및 체크리스트
- `pyproject.toml` / `uv.lock`: 프로젝트 메타데이터 및 환경 설정
- `.gitignore`: 불필요한 빌드/캐시 파일 제외 설정
